# Correios Toolkit

Projeto independente em HTML, CSS e JavaScript.

- Declaração de conteúdo: formulário com até seis itens, soma dos valores e geração de link oficial.
- Frete e prazo: acesso ao simulador oficial externo (sem integração de API nesta versão).

## GitHub Pages

Envie os arquivos à raiz da branch `main`. Em Settings > Pages, selecione Deploy from a branch, `main`, `/ (root)` e Save.

Não há credenciais nem dados pessoais pré-preenchidos. Os dados informados na declaração são enviados pela URL ao site oficial e podem ficar no histórico do navegador. A geração oficial depende da disponibilidade e compatibilidade do endpoint dos Correios.
